# Guía estética para futuras invitaciones

Estas pautas resumen las decisiones tomadas para la invitación de Zenia & Diego y sirven como punto de partida para nuevos diseños.

## Dirección visual

- Estética de acuarela suave, cálida y artesanal.
- Las imágenes deben integrarse con la página: evitar recortes duros, bordes marcados o secciones que parezcan pegadas encima.
- Usar un velo de color sobre las imágenes para unificar la escena con el resto de la invitación.
- El velo debe ser translúcido y difuminarse gradualmente hacia un fondo crema, especialmente en los bordes superior e inferior.
- Mantener una textura pictórica visible, pero sin detalles excesivamente nítidos ni aspecto fotográfico.
- Si una imagen tiene elementos blancos o transparentes, suavizarlos para que no queden cortes visibles sobre el fondo.

## Ilustraciones

- Preferir ilustraciones simples, relajadas y con pincelada acuarelada.
- Evitar contornos rígidos, objetos demasiado definidos y caras con mucho detalle.
- Las estrellas, llamas, flores y adornos deben tener bordes suaves y difuminados.
- Las ilustraciones pequeñas deben conservar la misma textura y nivel de definición que los fondos grandes.
- Para lugares reales, usar una referencia proporcionada por la pareja o una representación genérica claramente acuarelada; no inventar una arquitectura específica como si fuera una foto real.

## Tipografía y composición

- Combinar una serif elegante para títulos con una tipografía secundaria legible para la información.
- La tipografía debe mantener las tildes y caracteres del español.
- Dar prioridad visual a nombres, fecha, hora, parroquia y bodega.
- No hacer que los textos importantes se pierdan sobre la imagen: ajustar contraste y velo antes de agregar sombras fuertes.
- Mantener aire entre bloques y evitar que una sección quede sobrecargada o demasiado vacía.
- Los títulos de secciones pueden ajustarse individualmente; un título largo puede necesitar un tamaño menor.

## Botones y datos

- Botones de ubicación redondeados, discretos y coherentes entre parroquia y bodega.
- Usar el mismo tratamiento visual para ambos botones.
- Mostrar la fecha también en la ceremonia cuando sea necesario.
- El contador debe mostrar solo la información solicitada, sin horas si no aportan.

## Secciones

- Mantener una estructura clara: portada, cuenta regresiva, ceremonia, celebración, confirmación y detalles.
- La celebración funciona mejor con una imagen de fondo integrada y el texto sobre la imagen.
- La sección de regalos puede incluir una imagen acuarelada grande arriba del título y datos bancarios debajo.
- Para “Otros detalles”, incluir solo lo que se haya pedido; eliminar columnas o textos que agreguen ruido.
- La confirmación debe contemplar asistencia, restricciones alimentarias y una canción que no debería faltar.

## Paleta de referencia

- Fondo crema cálido.
- Terracota apagado para acentos y títulos.
- Verde oliva para velos, fondos y detalles.
- Amarillo suave/dorado para pequeños resaltados.
- Evitar rosados saturados; si aparece un rosado, llevarlo hacia terracota.

## Criterio de revisión

Antes de dar una versión por terminada, revisar la invitación completa en móvil y comprobar que:

1. Las imágenes se funden con el fondo.
2. Ningún elemento tiene más definición que el resto.
3. Los datos importantes se leen sin competir con la acuarela.
4. Los botones tienen el mismo estilo y tamaño visual.
5. La composición no queda dividida en tarjetas aisladas.
